# The Map Is Not the Territory

English translation of the Russian science-noir detective novel
*«Карта не есть территория»*, based on Alfred Korzybski's 1937 general-semantics
seminars at Olivet College.

**Status: not started.** This folder is a placeholder so that the Russian and English
editions can be built independently.

The Russian source is in [`../ru/`](../ru/); compiled PDFs are in the
[releases](../../releases).

A note for anyone picking this up: in Korzybski's writing the terminology carries
structure, not just meaning. The hyphens in "semantic-reactions" are load-bearing,
"is not" is an assertion rather than clumsy phrasing, and a translation that smooths
these out destroys the thing the book is about.
